## 零、适用范围与事件副本优先

- 本条目适用于常规副本生成。
- 由事件条目（<事件_中期试炼_...>、<事件_终期试炼_...>等）触发的副本，事件条目优先：参战人员、世界选取、时间限制、难度与奖励以事件条目为准；本条目只补齐事件条目未规定的部分（输出格式、奖励映射、CR表等）。
- 事件条目明确写“无视副本生成的投掷结果”时，不再执行本篇第一章的抽取流程；事件副本的世界仍须取自已知文艺作品IP，不得原创。

## 一、副本来源与世界选择

原则：副本均取已知文艺作品世界观，回廊绝不原创；遍历数据库选符合模块的世界，别出心裁不公式。

### 1. 抽取流程（五骰顺序锁定）

严格按第1~5骰的顺序，使用<公平骰池系统>取値：
【副本类型】+【题材大类】+【媒介来源】+【来源地域】+【IP热度】=【最终副本】。

硬性规则_骰值锁定：
- 五颗骰按顺序掷出，掷出即锁定。
- 不可协商、不可撤回、不可重掷、不可改骰、不可挑选有利结果。
- 即使组合牵强，也必须按结果推进；不得以“不合理”为由更换IP或重新生成。
- 每颗骰的原始値按<公平骰池系统>的格式记录为“R[批次号]/D[骰型]-[格号]=[原始値]”，并写入输出模板的「抽取记录」。
- 生成时掷定的奖励数值在结算时直接使用，禁止重掷（与<副本结算>一致）。
- D14取値：若<公平骰池系统>尚未列出D14，则本骰使用独立宏{{roll:1d14}}，同样登记原始値；其余四骰仍从骰池取値。

### 2. 副本类型判定（D4，第1骰）

1=【和平】/ 2=【阵营】/ 3或4=【血腥】。

- 类型骰只决定契约者之间的关系规则，不决定世界背景的危险程度。
- 首次副本：强制【和平】，不投类型骰；世界仍按第2~5骰生成；只匹配1名同为Lv.1的IP契约者队友，按<同人契约者降临法则>处理。

### 3. 主模块判定（第2~5骰）

① 题材大类（D14，第2骰）：确定世界的基础力量体系与叙事基调。
1玄幻 / 2奇幻 / 3武侠 / 4仙侠 / 5都市 / 6现实 / 7军事 / 8历史 / 9游戏 / 10体育 / 11科幻 / 12诸天无限 / 13悬疑灵异 / 14轻小说。
（题材只决定“世界骨架”，不决定具体作品；具体作品由后续骰值+IP校验锁定。）

② 媒介来源（D20，第3骰）：决定世界的叙事质感与规则表现。
1单机游戏 / 2电子竞技·网游 / 3手游·抽卡游戏 / 4Galgame·视觉小说 / 5网络小说 / 6实体名著·出版小说 / 7漫画 / 8TV动画 / 9剧场版动画 / 10真人电影 / 11电视剧·网剧 / 12特摄片 / 13跑团规则（TRPG） / 14桌游 / 15卡牌游戏（游戏王·万智牌等） / 16民俗·神话传说 / 17怪谈·新怪谈 / 18宗教典籍·史诗 / 19舞台剧·音乐剧·歌剧 / 20真实历史事件·纪录片。
（同一IP跨媒介时以本骰结果为准：投出“漫画”用漫画版设定与剧情节点，投出“TV动画”则包含动画原创篇章；不得混用其他媒介版本。）

③ 来源地域（D12，第4骰）：
1-3中国 / 4-5日本 / 6-7美国 / 8欧洲 / 9俄罗斯 / 10韩国 / 11其他 / 12全球共同·无特定地域。
- 欧洲（8）与“其他”（11）需再掷D6细分：
  欧洲_D6：1英国 / 2法国 / 3德国 / 4北欧 / 5东欧 / 6南欧。
  其他_D6：1东南亚 / 2中东 / 3拉美 / 4非洲 / 5大洋洲 / 6GM指定。
- 细分骰是第4骰的附随骰，不计入五骰；掷出后同样锁定，不可重掷。
- “地域”指IP的原作产地/文化归属，不是契约者的降临地点；降临地点由副本剧情决定。

④ 力量层级（不投骰）：不受限制——沿用原规则：100级契约者可能匹配到完全无魔的普通世界，1级新人也可能匹配到力量上限多元宇宙级的世界观（DC、漫威、完美世界等）。主线任务与力量层级、世界观背景不相关。

⑤ IP热度判定（D40，第5骰）：
较冷门1-15 / 中等16-25 / 较热门26-35 / 世界知名36-40。
禁止口胡、禁止原创不存在的世界。
（热度档位只用于校验候选IP的知名度；无标签版不启用标签系统。）

### 4. IP校验与锁定（不投骰，第5骰后执行）

- GM按【题材大类】【媒介来源】【来源地域】【IP热度】4项结果，报出1~3个全部符合的真实IP候选；玩家选择或GM指定其一，锁定为副本世界。玩家只能在候选中选择，不得要求扩大候选范围或更改骰值。
- GM报不出完全匹配的真实IP时，按以下顺序放宽，取最接近的真实IP：
  1. 先放宽【IP热度】档位；
  2. 再看【来源地域】；
  3. 最后看【媒介来源】。
  【题材大类】为硬约束，不得放宽。
- 最多放宽两项；每次放宽必须在「抽取记录」的「放宽项」中写明：原骰值→实际属性及原因。若放宽两项后仍无匹配，取题材相同、综合最接近的真实IP，并注明“综合最接近”。
- 禁止因组合牵强而重掷、改骰、跳过本次生成或原创世界观。
- 锁定后，时代背景、力量层级、世界细节一律以该IP原作为准；副本剧情以原作剧情节点为骨架。
- 允许回廊对原作角色进行规则化强化（等级/阶位/词条/机制），但不得改变其原作性格、立场与未介入时的关键命运节点；禁止捏造原创反派与世界观设定。

## 二、三种世界生成逻辑与任务防暴走规范

前提：所有任务与敌人必须以原著架构与既定时间线为骨架；允许回廊强化数值与规则，禁止捏造原创反派；常规副本的契约者必须同阶位（事件副本按事件条目执行，可突破此限制）。
核心原则：支线不得与主线矛盾；任务必须符合契约者【阵营偏向】（善良守序不派混沌邪恶任务，反之亦然）。

### 1. 和平世界（绝对禁PVP / 兼容极端PVE）

- 核心机制：“和平”仅指契约者间禁PVP，绝非世界背景和平——环境可能极其血腥惊悚，致死率依然极高。
- 降临组队：全员同地降临、在场可交互；共享主线；展示全员完整信息（姓名/等级/职业/天赋）。
- 信息展示：契约者的职业/天赋在副本开场叙述中展示实际值；名单行保持模板格式，不额外增删字段。
- 任务生成防暴走（微观四步法）：
  1_阵营锚定：检索契约者偏向，禁止派发底线冲突任务。
  2_微观切入：与副模块机制深度绑定；投放至原著宏大事件局部，不干涉主角团核心走向。
  3_具象目标：确立可验证的存活/逃生/护送/解谜目标，严禁“存活X天”模糊任务。
  4_最终阻碍：任务终点必遇与主线/副模块对应的【核心阻碍者/最终死局】——战斗模块为常规BOSS；智斗/解谜模块为原著高智商敌对NPC、极难机关或规则杀，绝不强制无脑物理战斗。
- 违规惩罚：强行伤害契约者者判违规：系统通缉 + 全属性临时降10% + 死亡掉落率激增；违规击杀无奖励。

### 2. 阵营对抗世界（借势与军备竞赛）

- 核心机制：互斥对立，依托原著势力阵营战争；契约者进本时自主选择加入一个阵营，回廊不强制改选。
- 战力平衡：回廊按双方总战力（人数、等级、CR、装备/技能/血统综合）裁定；弱势方获得补偿（等级临时修正、专属增益、原著势力支援或额外NPC队友，由回廊裁定并在副本开场明示），确保双方总战力相当，不出现开局单方面碾压。例：一边四名12级契约者，另一边只有两名契约者，则回廊给两人足以对抗四名12级的补偿。
- 降临组队：同阵营同地、敌对不同地降临。
- 若一方无人选择：回廊以额外奖励引导，不强制改选；仍无人时，该阵营由原著NPC填充。
- 信息展示：名单行只展示称号、真名、等级与阵营，不公开职业/天赋；职业/天赋信息不进入名单。
- 任务生成防暴走：
  主线互斥：对立阵营生成绝对冲突的主线（例：A保护目标撤离，B必须击杀该目标）。输出模板中的主线为{{user}}所属阵营的主线，敌对阵营主线不公开。
  死战明示：任务描述明示“与敌对阵营直接冲突，不死不休”。
- 专属机制：
  阵营声望：完成支线或击杀敌对目标获得；极高声望可在专属军需处兑换原著势力核心力量。
  成就替换：副本成就的达成条件强制替换为【战场目标】（猎杀原著敌对势力高价值目标），星级与奖励梯度不变。

### 3. 血腥世界（黑暗森林绞肉机）

- 核心机制：纯契约者PVP博弈，无阵营约束；固定小队不强制拆队、不强制互相猎杀，成员可正常协作与共享情报。
- 降临组队：强制全员分散降临（间距≤500米）；主线不共享；展示姓名与等级，职业/天赋标【未知】（需侦查）。
- 信息展示：名单行只展示称号、真名、等级；职业/天赋在开场叙述中标“未知（需侦查）”，不进入名单。
- 主线与任务：输出模板中的主线为{{user}}（当前视角契约者）的主线；其他契约者的主线不公开，由GM私下生成。
- 任务生成防暴走：
  存活名额：禁止“仅活一人”死局，按参赛契约者总数固定25%~40%存活名额（一个固定小队全员共占同一个名额；小队全灭视为该名额淘汰）。
  动态博弈主线：主线围绕“生存名额”与“猎杀指标”展开，逼迫假结盟、背叛与合纵连横。
- 专属机制（血腥钥匙）：PVP无惩罚；击杀契约者必掉【血腥钥匙】，开启随机抽取对方UP的30%~50%及一件非绑定装备/技能卷轴。

### 4. 共通任务

- 支线：依附原著背景，接头人为原著群体或个体；输出模板只展示{{user}}当前可获取的支线，未接触的支线不提前公开。
- 隐藏：触碰原著【固有角色】或截胡机缘；进本仅给暗喻谜语线索；按{{user}}视角生成，其他契约者的隐藏任务不公开。
- 世界事件：原著注定发生的大事件，可介入或忽略；忽略则按既定逻辑自动推进。

## 三、契约者匹配机制（多人副本）

按优先级匹配：
- 0_个体：契约者含地球人原创角色与各世界（动漫/小说/游戏/电影）IP角色；IP角色必须存在被匹配的合理契机，具体IP与角色由GM按契约者的核心特色（职业/血统/天赋/战斗风格）裁定，不使用标签表。
- 1_CR评价：匹配CR（回廊态度评级）相同或极度相近者（CR10.0炼狱只匹配同档，高危玩家互相养蛊，不干扰常规玩家）。
- 2_位阶：满足CR后匹配同一位阶。
- 3_等级：满足上述后尽可能匹配等级相近者。
原则：所有面板契约者真名公开，禁止代号或假名。
- 事件副本按事件条目规定的参战人员执行，可突破上述匹配与同阶位限制。

## 四、敌人生态与动态难度锁定

生成基准：以{{user}}进本时的当前等级与位阶为基准，叠加CR态度难度影响，一次性生成并锁定所有常规敌人等级。
- 敌人按<敌人模版设计>生成；固有角色按<固有角色锚定与战力表现>锚定，不得隐藏其等级/位阶。
- 敌人初始化是生成步骤，不单独输出为XML区块；必要时在副本背景或遭遇描述中体现。
- 事件副本的敌人与难度以事件条目为准；事件条目未规定时，才使用本篇CR表。

## 五、CR难度修正（生成时锁定）

说明：CR即回廊态度评级；本表只负责生成时锁定敌人基准等级与强化。奖励倍率、连胜压力与CR增减以<动态难度与CR系统>和<副本结算>为准；本表与该条目冲突时，以该条目为准。

漠视_1.0至2.9:
  生机评估: 正常运转
  难度: 副本敌人基准等级不变，无额外强化。

观察_3.0至4.0:
  生机评估: 略有风险
  难度: 副本敌人基准等级+2，精英怪刷新比例微调。

关注_4.1至6.0:
  生机评估: 危机四伏
  难度: 副本敌人基准等级+4，所有敌人基础属性提升10%。

重视_6.1至8.0:
  生机评估: 险象环生
  难度: 副本敌人基准等级+8，所有敌人获得1个特化词条。

期待_8.1至9.9:
  生机评估: 九死一生
  难度: 副本敌人基准等级+16，所有敌人获得2个特化词条，BOSS获得针对性机制与二阶段狂暴。

炼狱_10.0:
  生机评估: 十死无生
  难度: 副本敌人基准等级+32，且阶位+1（若五阶则强化为超脱），全域环境附加致命规则压制。敌人数值与机制彻底突破当前阶位上限。

## 六、副本生成格式（三大强制输出区块）

规则：严格按三大区块一次性完整输出，严禁在任务名前增添任何序号、圆点或破折号。
- <副本任务>：世界元数据 + 主线×1 + 支线×3 + 隐藏×2。
- <副本世界事件和成就列表>：世界事件×2 + 副本成就×6。
- <副本人物生成>：契约者名单 + 固有角色。
- 敌人初始化不单独输出；按<敌人模版设计>生成并在副本内锁定。

### 1. 世界元数据（写入<副本任务>）
副本名称/副本背景/副本来源/副本类型（和平/阵营/血腥，三选一）/时间限制/抽取记录。
- 副本名称：建议《IP名》·篇章/事件名。
- 副本背景：原作时间线节点 + 核心冲突 + 契约者切入点；不得剧透未接触的隐藏任务。
- 副本来源：IP名 + 锁定媒介 + 地域 + 热度档；必须与「抽取记录」一致。
- 时间限制：常规副本3~14天叙事时间；事件副本以事件条目为准。剩余不足25%时GM必须明确提醒。
- 抽取记录：五骰原始値、批次号、锁定IP、放宽项；格式见输出模板。

### 2. 任务与事件（写入<副本任务>与<副本世界事件和成就列表>）
主线×1、支线×3、世界事件×2、副本成就×6、隐藏任务×2。
- 主线×1：完成条件、失败惩罚、奖励。
- 支线×3：可选，进本明示条件与奖励，不得与主线冲突。示例：【采样专家】获取一份丧尸血样并带出蜂巢。奖励：40 UP、30 EXP、【对应品质物品或装备】。
- 世界事件×2：正在发生的宏观局势或不可逆灾难；固有角色正推进大势；玩家可介入改变，忽略则按既定逻辑自动推进。
- 隐藏任务×2：触碰世界根本的终极途径，接触原著【固有角色】，火中取栗；进本仅给隐晦线索。
- 成就×6：绑定世界观的终极挑战，★至★★★★★★（必含代表世界观上限的终极成就）；明示条件但极难达成；每项必须有成就名称、达成条件与奖励。
- 输出模板只输出{{user}}当前视角可获取的主线、支线、隐藏任务；其他阵营或契约者的任务不公开。

### 3. 固有角色与敌人
- 固有角色写入<副本人物生成>，按<固有角色锚定与战力表现>展示，格式：名称 (Lv.X | 阶位)；只列本副本已登场或明确可接触的角色，未登场者不提前公开。
- 敌人按<敌人模版设计>生成并锁定；不单独输出区块。

### 4. 契约者名单（写入<副本人物生成>）
- 展示所有契约者的称号+真名+等级：`[称号]真名 Lv.X`（无称号写[无称号]）。
- 阵营世界在每名契约者后标【阵营】；非阵营世界省略。
- 职业/天赋按世界类型在开场叙述中展示：和平世界展示实际值；阵营世界不公开；血腥世界标“未知（需侦查）”。
- 真名公开，禁止代号或假名。
- 名单行严格保持模板格式，禁止增删字段或附加说明。

## 七、任务奖励基础规范

核心原则：
- 所有任务奖励（UP/EXP）为基础值；最终结算按<副本结算>的评价倍率×CR倍率×位阶修正乘算。
- 物品/装备符合{{user}}当前阶位；称号由<副本结算>按评价授予，不在本条目奖励中生成。
- 品质序列：白→蓝→金→紫；银为剧情特殊品质，仅六星成就、隐藏BOSS等产出（见<品质稀有度规范>）。
- 物品类型缩写：耗=消耗品，装=装备，卷=技能卷轴，特=特殊物品。
- 所有奖励在生成时掷定并锁定；结算直接使用，禁止重掷（与<副本结算>一致）。

奖励随机化（数值与物品由宏掷定；AI必须把骰值按方括号内“区间=文字”映射转成文字输出，禁止照抄骰值或映射）：
- 物品输出格式：【品质】类型：具体物品名（具体物品名出自当前副本世界观，禁止通用化）。
- 转换示例（支线物品）：品质骰=5、类型骰=6 → 按括号映射输出“【金色】装备：具体物品名”。
- 品质按{{user}}阶位封顶，高难度任务/成就可+1档。

## 八、输出格式保真（正则匹配硬性要求，违反即判定输出无效）

- 成就梯度必须输出全部6行，按★→★★★★★★顺序递增，禁止省略、合并或改序。
- 所有[占位符]必须替换为实际内容，严禁原样输出。
- 字段名、##标题、标签闭合必须与下方模板逐字一致，禁止增删字段或改变顺序。
- 字段名与冒号使用半角符号；正文内容中的中文标点不受此限。
- 副本类型只能填一个：【和平】或【阵营】或【血腥】，禁止三个全写。
- 「抽取记录」必须完整输出五骰原始値、批次号、锁定IP与放宽项，禁止省略；地域细分仅在第4骰为欧洲/其他时填写，否则写“无”。
- <副本人物生成>标题规则：`## 契约者名单`、`## 固有角色`必须原样输出，禁止附加括号注释。
- <副本人物生成>列表规则：
  契约者列表格式：`[称号]真名 Lv.X【阵营】`（非阵营世界省略【阵营】；多个以逗号分隔）。
  固有角色列表格式：`名称 (Lv.X | 阶位)`（多个以逗号分隔）。
  均禁止编号（1. 2.）与破折号（-）前缀，禁止自由发挥的说明行。- <副本人物生成>契约者字段规则：`契约者:`字段必须原样输出，禁止用“己方阵营/敌方阵营”等自定义标题替代；阵营世界在每名契约者后标注阵营，不得改写字段名。
- 成就行格式：`★ 探索级：[成就名称 | 难度 | 奖励]`，六行均须包含成就名称、达成条件与奖励。
- 同一IP跨媒介时，以「抽取记录」中第3骰锁定的媒介版本为准，禁止混用其他版本设定。
