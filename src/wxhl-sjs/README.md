# wxhl-sjs — 世界书事件补录

本目录存放《无限回廊》世界书及事件文档，用于把各条世界线路的「中期试炼 / 终期试炼」事件补录为世界书条目。

## 文件

| 文件 | 说明 |
| --- | --- |
| `无限回廊9.9版.json` | 原始世界书快照（157 条目） |
| `事件_火影忍者路线.txt` | 事件文档，共 27 个 `<事件_xxx>` 块 |
| `无限回廊9.10版.json` | 补录后的世界书（184 条目），可直接导入酒馆 |

## 新增条目约定

新增 27 个事件条目，设置与既有「事件_*」条目保持一致：

- 激活策略：蓝灯（`constant: true`）
- 默认状态：关闭（`disable: true`）
- 关键词：无（`key: []`、`keysecondary: []`）
- 插入位置：角色定义之前（`position: 0`）
- 深度：`depth: 4`
- 插入顺序：`order: 330`–`356`，位于 `<事件设定>`（300）与 `</事件设定>`（400）之间
- 条目名：取自文档中的 `<事件_xxx>` 标签
- 条目正文：逐字复制文档中 `<事件_xxx>…</事件_xxx>` 整块（含标签）

`originalData` 保持原样未动（源文件中它本就是旧版快照，酒馆导入以 `entries` 为准）。

## 重新生成

```bash
node scripts/wxhl-sjs/build-worldbook.js
```

脚本会校验事件数量、重名、正文一致性与条目设置；任何一项不符都会直接报错。
