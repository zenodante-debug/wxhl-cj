## 已修正的内部问题

1. **投骰锁定**：删除“重掷最违和的一项”；新增硬规则——五骰掷出即锁定，不可协商、不可撤回、不可重掷、不可改骰、不可挑有利结果。
2. **无匹配 IP 兜底**：改为“取最接近的真实 IP”，按「热度 → 地域 → 媒介」放宽，最多两项；题材为硬约束；每次放宽写入抽取记录。
3. **骰子编号**：修正 `D40①` 等错位；去掉 ①~⑤ 与“第 N 骰”混排；力量层级单列为“不投骰”；地区 D6 细分补了具体映射。
4. **阵营归属冲突**：统一为“契约者自主选择阵营 + 回廊平衡双方战力”，删除“强制分配对立阵营”；补了一方无人选择时的 NPC 填充规则。
5. **固定小队**：明确为“仍分散降临，但不强制拆队、不强制互相猎杀”；存活名额中全员共占 1 个名额，全灭视为名额淘汰。
6. **四大区与模板对不上**：改为三大 XML 区块，并逐项映射；固有角色名单从“世界元数据区”移到 `<副本人物生成>`，与模板一致；敌人初始化明确为内部生成步骤，不单独输出。
7. **职业/天赋展示冲突**：不改名单行格式，改为在副本开场叙述中展示——和平实际值、阵营不公开、血腥标“未知（需侦查）”。
8. **模板说明文字**：把 `（多个以逗号分隔…）` 这类说明移出模板；统一成就行空格；副本类型明确三选一；半角符号规则限定为字段名与冒号。
9. **成就缺名称**：模板成就行由 `[难度 | 奖励]` 改为 `[成就名称 | 难度 | 奖励]`，与 `<副本结算>` 要求展示成就名称对齐。
10. **抽取记录**：在 `<副本任务>` 新增 `## 抽取记录`，记录批次、五骰原始值、地域细分、锁定 IP、放宽项。
11. **悬空引用**：`<敌人生成规则>` → `<敌人模版设计>`；`同人契约者匹配流程` → `<同人契约者降临法则>`；删除无标签版里的“下篇标签”“核心特色标签 1d50”；CR 表改为引用 `<动态难度与CR系统>` 与 `<副本结算>`。
12. **奖励细节**：RP 区间补骰式（1d3 / 1d3+1 …）；修正错误的转换示例（原文“品质 3、类型 2 → 金色装备”在所有当前映射里都不成立，改为“品质 5、类型 6 → 金色装备”）；“F级无结算”改为“失败=F级（主线失败=抹杀，不进入结算）”；“最低保底”明确为主线奖励；称号移到 `<副本结算>`；补品质序列与物品类型缩写。
13. **事件副本优先级**：新增第零章——事件条目优先，常规副本的同阶位、时间限制、难度、奖励规则可被事件条目覆盖。
14. **原著忠实度**：把“100%深耕原著”改为“以原著架构与时间线为骨架，允许回廊强化数值与规则”，与事件条目里的回廊强化一致；同时保留“禁止原创反派/世界观”。
15. **术语与层级**：统一“固有角色”、`IP` 大小写、“解谜”；标题层级改为 `## 零/一/二…` + `### 1/2/3…`。

## 我替你做的判断（请重点复核）

- **放宽顺序**：热度 → 地域 → 媒介，题材不放宽，最多两项。
- **阵营平衡**：补偿形式写成“等级临时修正、专属增益、原著势力支援或额外 NPC 队友”，由回廊裁定并在开场明示。
- **固定小队**：按“分散降临但不强制拆队/互杀”理解；若你的本意是“固定小队整队同地降临”，这一条要改。
- **阵营世界的职业/天赋**：原文只说和平要展示、血腥要标未知，阵营没写；我按模板的名单格式判断为“不公开”。
- **成就行加名称**：这会改变成就行的字段数，如果你的正则按旧的 `[难度 | 奖励]` 匹配，需要同步改。
- **CR 表**：只保留生成时的难度修正；奖励倍率、连胜压力、CR 增减交给 `<动态难度与CR系统>` 和 `<副本结算>`。
- **D14 骰**：`<公平骰池系统>` 目前只有 D4/D6/D8/D10/D12/D20/D30/D40/D50，没有 D14。整理稿写了一个兜底：D14 用独立宏 `{{roll:1d14}}`。更干净的做法是给骰池补一行 D14（10 格）。
- **地域 D6 细分表**：原文只说“可再 D6 细分”，没给映射；我补了欧洲/其他的六项表，可按你的设定替换。
