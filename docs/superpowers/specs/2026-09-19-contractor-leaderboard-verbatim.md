## 目标结构（实现时按此建类型）

现有类型是 `RankItem { rank, name, lv, team }`。需要扩成：

```ts
export interface RankItem {
  rank: string      // 名次，字符串，如 '1'
  name: string      // 称号，含书名号，如 '「天榜之首·执剑镇国」'
  lv: string        // 等级，字符串，如 '100'
  team: string      // 势力短名，如 '中国特管局' / 'OETA' —— 供 UI「所属」列与副本生成匹配池使用
  realName: string  // 真名，如 '燕琉璃'
  gender: string    // '女' / '男'
  identity: string  // 身份，即「势力+职务」，如 '中国特管局总局长'
  className: string // 职业，如 '银色唯一职业·太虚剑主'
  bio: string       // 人设一句话，如 '压级五年拒绝终局试炼的摸鱼剑仙'
}
```

**约定**：
- `name` 一律保留原文的书名号 `「」`。
- `team` 取**势力短名**（见下表对照），不要带职务。
- `identity` 保留原文的完整身份（含职务）。
- 原文里 `说明` 字段的括号 `(...)` **不要**写进任何字段。
- 原文职业写法如 `银色唯一职业·太虚剑主`、`金色职业·超级士兵`、`蓝色职业·嗜血狂战士` —— `className` 原样收，**不要**把品质拆出去。
- 天榜/地榜/玄榜/黄榜/人榜的 `key` 与 `title` **保持现状**（`data.ts` 里现有 `人榜`/`黄榜`/`玄榜`/`地榜`/`天榜` 与其 title 文案不变），只替换 `items`。
