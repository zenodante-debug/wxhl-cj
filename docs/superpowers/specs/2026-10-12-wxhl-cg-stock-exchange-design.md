# wxhl-cg 回廊交易所 · 设计文档

日期：2026-10-12
状态：已于 2026-10-12 按用户十条反馈重做（§4–§14 为修订后版本）

## 1. 背景与目标

为「无限回廊」小手机新增一个**炒股 app**：参考《杀戮尖塔》mod「杀跌尖塔」（SpireStocks，素材已提取存于 `docs/reference/spire-stocks-strings.txt`），做单机版交易所。

已确认的边界（2026-10-12 重做后）：

- **单机**：不做联机、不做全球榜、不做徽章、不做"本局/结算"概念。
- **形态**：独立脚本项目 `src/wxhl-cg`，通过 `window.parent.WxhlCg` + `initializeGlobal('WxhlCg', …)` 双通道暴露接口；小手机（wxhl-003）只新增一个 app 图标调起。
- **窗口**：居中浮窗，**不是**全屏铺满——桌面端 `min(980px,94vw) × min(92dvh,920px)`（圆角 18px），手机端 `visualViewport − 12px`（圆角 14px），尺寸规则与状态栏窗口一致。
- **行情**：脚本加载即开跳，**常驻** 10 秒/跳（不依赖面板是否打开，也不监测楼层）。
- **存档**：浏览器 localStorage（跨聊天、跨档持久）。
- **货币**：交易所内部记账，与主卡 UP 双向兑换，1 UP = 1 交易所币，双向各收 1% 手续费。
- **破产清算**：累计已实现亏损越过破产线 250 → 自动按固定瀑布变卖主卡资产抵债（见 §8）。
- **不做借贷/典当**：玩家可在正文里找势力借钱；交易所不内置借贷、不做典当行。
- **颜色口径**：**红 = 亏损，绿 = 盈利**（与 A 股惯例相反，用户明确要求）。

## 3. 数据模型（localStorage）

key：`wxhl-cg:account`（JSON，zod parse，版本字段 `v` 便于迁移）。

```ts
interface ExchangeAccount {
  v: 3;                                  // v1/v2 存档自动迁移（见 §3.1）
  cash: number;                          // 交易所币，可为负
  positions: Position[];                 // **一笔一行**：同一只股可多笔，也可多空对冲
  prices: Record<string, number>;        // 股票代码 -> 现价
  priceHistory: Record<string, number[]>;// 每股票最近 60 跳
  openPrices: Record<string, number>;    // 开盘基准价：每次脚本加载快照（§4）
  tick: number;                          // 累计跳动数
  netInvested: number;                   // 净投入（币）：Σ存入所得 − Σ取出所扣
  debt: number;                          // 破产清算后未抵完的欠款（跨档背着）
  bankruptcyCount: number;
  cumulativeLoss: number;                // 累计已实现亏损（破产线判定用）
  frozen: boolean;                       // 破产欠款未清 → 冻结（禁止开仓）
  news: ActiveNews | null;
  newsCooldown: number;
  logs: LogEntry[];                      // 交易所日报（存档上限 200，界面显示最近 50）
}

interface Position {
  id: string;               // 唯一标识，平仓按它定位
  code: string;             // 股票代码
  side: 'long' | 'short';
  qty: number;              // 股数
  entryPrice: number;       // 这笔的开仓均价
  leverage: number;         // 1–100
  margin: number;           // 这笔占用的保证金
}

interface LogEntry {
  tick: number;
  time: string;             // 现实时钟 HH:MM:SS
  kind: 'news' | 'trade' | 'system';
  text: string;
}
```

### 3.1 存档版本

`v` 变更必须带迁移（终审 C1 教训：只改 schema 不迁移会把老存档静默清空）：

- `v === 3`：按 `AccountSchema` 校验，失败则 `console.warn` + 重开新账户；加载时 `openPrices` 重新快照。
- `v === 2`：走 `migrate()` —— 持仓 `record` 拆成**一笔一行**（补 `id`/`code`），其余字段（含 `netInvested`/`logs`）原样保留。
- `v === 1`：同上，另外丢掉 `loan/loanState/deathMarked`、补 `openPrices`/`logs: []`/`netInvested`（= 迁移时的现金 + 持仓权益，即"盈亏从迁移那一刻重新起算"）。
- 其他版本 / JSON 损坏：`console.warn` + 新账户。**老版本一律迁移，不清空**（终审 C1 教训）。

## 4. 行情引擎

- **跳动**：app 打开时 `setInterval` 10s 一跳；`tick++`；几何随机游走 `price *= exp(σ·N(0,1) + drift)`，σ 按股票分档；价格下限 0.01（不清零退市）。
- **股票池**（10 只，波动低→很高，名称/代码初稿可调）：

| 代码 | 名称 | 势力 | 波动档 | σ |
|---|---|---|---|---|
| TGJ | 特管局后勤 | 特管局 | 极低 | 0.4% |
| OETA | OETA 安保 | OETA | 低 | 0.8% |
| LHJ | 零号局情报 | 零号局 | 中低 | 1.2% |
| EJS | EJSSA 竞技 | EJSSA | 中低 | 1.6% |
| FM | 非盟商会 | 非盟 | 中 | 2.2% |
| PLH | 泛联控股 | 泛东亚联合体 | 中高 | 3.0% |
| SJH | 圣辉教会 | 神圣教会 | 中高 | 3.8% |
| FZJT | 方舟集团 | 方舟集团 | 高 | 5.0% |
| RCJJ | 瑞辰基金会 | 瑞辰基金会 | 很高 | 6.5% |
| EML | 恶魔旅团黑产 | 恶魔旅团 | 极高 | 9.0% |

- **新闻**：每 5–10 跳随机抽一条（按股票加权），标题分利好/利空，**实际冲击 ±（1–3 × σ）独立 roll，可能与标题相反**；冲击以 drift 形式作用于其后 3 跳。新闻池基于提取的尖塔素材改写为回廊势力版。
- **开盘基准价**：`openPrices` 在**每次脚本加载时**快照当刻价格。涨跌幅与走势图基准线都按它算（"开盘"= 本次会话开始），因此没有"局"的概念也能有可读的涨跌零轴。

## 5. 交易规则（照搬原作数值）

- **下单输入是金额 = 保证金**（你实际掏的钱）：名义金额 = 金额 × 杠杆，股数 = `floor(名义 / 现价)`（向下取整，所以实际保证金 ≤ 输入金额）。界面同时显示 金额 → 名义 → 股数 三个数，并把佣金/印花税摊开。
- **同一只股可以同时持有多笔**（一笔一行、逐笔平仓），也**可以多空同时持有做对冲**。
- 做多/做空；杠杆 1–100 倍；保证金 = 名义价值 / 杠杆。
- **最低保证金 5**：低于此的下单直接拒绝（照原作"保证金至少 5 金币"）。
- **佣金**：买卖双向，`clamp(成交额 × 1%, 下限 1, 上限 保证金 × 10%)`。
- **印花税**：卖出方 `min(成交额 × 0.1%, 保证金 × 1%)`（平多、开空收；强平、清算也收）。
- **下单预览**：`tradePreview()` 与 `openPosition()` 同算式但不动账本，界面实时显示"这单要花多少（保证金 + 佣金 + 印花税）"。
- **强平**：每跳检查，持仓净值跌破维持线（净值 ≤ 保证金 × 5%，即做多强平价 = 开仓价×(1−0.95/杠杆)）即按现价强平，费用照收。（2026-10-12 实现期修订：原稿「保证金 ≤ 名义价值 × 5%」会使 >20 倍杠杆开仓即破线（1/杠杆 < 5% 恒成立），与 1–100 倍设计矛盾，故维持线改按保证金计。）
- **强平可见性**：走势图上画出强平线，持仓行显示"距强平 x%"并高亮离强平最近的一笔——不再"莫名其妙被强平"。
- **杠杆利息**：杠杆 >20 倍时，每跳按名义本金收利息（费率 = (杠杆−20) × 0.01%，快进快出税）。
- **破产线**：累计**已实现**亏损 > 250 自动触发破产清算（§8）。浮亏不计入（否则开仓瞬间就触发）。

## 6. UP 兑换

- 读写 `stat_data.契约者.经济.UP`，照抄 `src/wxhl-003/market/store.ts` 的 Mvu 读写模式（`Mvu.getMvuData` 最新楼层 → 改 → `Mvu.replaceMvuData`）。
- 存入：扣 UP → 加交易所币 ×0.99（1% 手续费）；取出反向同样 1%。
- **只给预设按钮，不手填数字**：存入 `100UP / 1000UP / 一半 / 全部`（按 UP 计），取出 `100 / 1000 / 一半 / 全部`（按币计，到手 = 币 × 0.99 UP）；超出可用量自动夹到上限，为 0 时按钮禁用。
- 资产卡里**现金与 UP 并列显示**，随时看得见自己有多少 UP。
- 读不到 MVU（如界面不在楼层上下文）：toastr 报错、账本不动。
- **主卡 UP 允许为负**（2026-10-12 用户确认，游戏内已实测）。交易所侧语义：UP 为负时**取出照常**（UP 向 0 回升）；**存入被拒绝**（会让欠额更深），报错不动账本。UP 可扣到恰好 0。

## 7. 账户指标

交易所主面板右上显示的六个数字（`engine/metrics.ts` 纯函数计算）：

| 指标 | 定义 |
|---|---|
| 现金 | `acct.cash`（交易所币，允许为负） |
| UP | 主卡 `契约者.经济.UP`（每跳/每次兑换后重读） |
| 持仓权益 | Σ(保证金 + 浮动盈亏) |
| 净投入 | 累计存入所得币 − 累计取出扣掉币（已含兑换手续费） |
| 净资产 | 现金 + 持仓权益 **− 未清欠款**（欠款是真的负债，不计就会高估家底——终审 I5 修订） |
| 总盈亏 | 净资产 − 净投入（"我到底赚没赚"） |
| 破产线 | 累计已实现亏损 / 250，带进度条 |

## 8. 破产清算 · 资产变卖瀑布

**触发：自动**。累计已实现亏损越过 250 即触发（`shouldGoBankrupt`），无手动入口、无确认弹层——这是惩罚，不是选项。

严格按序变卖，每类卖完仍不足才动下一类；同类内从最便宜卖起，够抵债即停：

1. **交易所持仓 + 现金**：持仓按现价强平（佣金印花税照收）。
2. **背包物品**（`stat_data.契约者.背包`）：按市场基准价——品质查 `BASE` 表（`src/wxhl-003/market/priceTable.ts`）× 归一阶位²。
3. **装备七槽**（`stat_data.契约者.装备`）：同上定价；卖掉的槽**整槽重置为空槽形状**（`EMPTY_EQUIP_SLOT`，与 `statusbar/core.ts` 脱下装备同形），不能只清名称——残留的装备防御/伤害骰仍会被当装备读。
4. **通用技能**（`stat_data.契约者.通用技能`，record）：逐个移除，定价 = 品质查 BASE 武器列 × 玩家当前归一阶位²；品质缺失/不可解析 → 按白色兜底并 console.warn。
5. **职业**（`stat_data.契约者.职业`）：`稀有度` 当品质查表（紫色职业→紫、金色职业→金……）× 阶位²；重置为 `{名称:'无'}`（schema prefault 形状）。
6. **血统**（`stat_data.契约者.头部.血统`）：品质查表 × 阶位²；重置为 `{名称:'普通地球人类', 品质:'白色'}`。
7. **天赋**（`stat_data.契约者.头部.天赋`）：品质查表 × 阶位²；重置为 `{名称:'无'}`。

待偿额 = 当时的累计已实现亏损。清算所得先抵债，溢出退回现金；**抵不完的部分继续背着**（`debt` 字段，跨档持久）：账户进入**冻结**（禁止开仓），可在资产卡用现金「清偿」，清偿后解冻。清算后累计亏损计数归零，`bankruptcyCount++`。

原子性：先快照交易所账本，MVU 写回失败则整体回滚、记日志、**下一跳自动重试**（不半清算、不阻塞行情、不刷屏提示）。

## 12. 测试

vitest 单测 engine（纯函数，不碰酒馆接口）：

- stocks/types：股票池不变量、账户字段默认值与"借贷字段已移除"。
- market：价格波动非负、下限 0.01、历史上限、σ 分档生效。
- news：新闻池覆盖每只股票、ttl 3 跳、冲击幅度 ∈ [σ, 3σ]、冷却期不抽。
- trading：佣金下限 1/上限 10%、印花税上限 1%、最低保证金 5、无货/冻结拒绝、`tradePreview` 与实际扣款一致、强平线数值、杠杆利息只在 >20 倍收。
- bankrupt：破产线只认已实现亏损、已有欠款不重复触发。
- metrics：持仓权益/净投入/总盈亏、日报倒序与 50/200 双上限。
