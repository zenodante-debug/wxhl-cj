# 无限回廊 · 工坊 app（生产制造系统）设计文档

日期：2026-09-21
归属：`src/wxhl-003/crafting/`（小手机新图标，不立新项目；wxhl-005 已废弃删除）

## 1. 背景与目标

无限回廊世界书已有完整的生产制造规则（DC 公式、五档结果、材料损毁、署名刻印），但目前全靠 AI 自觉执行：骰子要"GM 预埋骰池"防口胡，DC 修正、材料扣除全靠 AI 记得。

本设计把生产制造做成小手机的一个新 app「工坊」：**一切确定性机制由代码强校验**（DC 计算、掷骰、材料扣减、成品生成、变量写入），AI 只负责风味（成品毒舌备注、自定义图纸内容）。与自由市场"装备价格强校验"同一思路。

核心约束：**主卡 MVU 变量结构零改动**。配方数据存小手机聊天变量；图纸做成背包常规物品。

## 2. 决策记录（已与用户确认）

| 决策点 | 结论 |
|---|---|
| 副本自由度 | 不碰。工坊是副本外的纯增量系统 |
| 配方存储 | 小手机聊天变量（`getVariables({type:'chat'})`），不进 MVU schema |
| 图纸形态 | 背包常规物品（名称前缀「图纸·」），配方 JSON 内嵌物品 catchall 字段 + 手机本地备份 |
| 图纸获取 | AI 生成图纸**候选**，付 UP 购买才入库；副本掉落/市场购买为另外合法来源 |
| 图纸定价 | 装备图纸 = 成品一阶中值 × 2 × 阶位系数；道具图纸 = 成品单价 × 20 × 阶位系数（阶位系数 = x²） |
| 图纸转卖 | 可挂自由市场，溢价上限沿用成色规则（金 +50% / 紫 +100%） |
| 成品描述 | 模板自动生成结构化字段；玩家可手动编辑；可随时调 AI 补一段惊悚乐园风毒舌备注 |
| 集成方式 | 小手机桌面新图标，代码在 `src/wxhl-003/crafting/`，结构照抄 `market/` |

## 3. 总体架构

```

├── store.ts            # pinia：配方库、材料档案（聊天变量持久化）+ MVU 读写
```

- 桌面集成：`App.vue` 新增图标（🛠️）+ `currentView` union 加 `'crafting'` + `appSubs.crafting` + `openCrafting()`。

## 4. 变量读写清单（主卡 MVU 路径，权威源 = 用户 registerMvuSchema）

**只读：**

| 路径 | 用途 |
|---|---|
| `契约者.头部.阶位` | 成品阶位上限（≤ min(契约者阶位, 生活技能阶位)） |
| `契约者.头部.姓名` | 杰作署名刻印 |
| `契约者.属性.基础.STR/AGI/CON/PER` | 制作检定（注意：用**基础属性**，非实际属性、非属性修正值） |
| `契约者.通用技能.${技能名}.{分类,阶位,等级}` | 生活技能判定：默认按技能名与行业名完全匹配（如名为「锻造」的技能）；手机侧存一张行业→技能名映射表，玩家可手动改 |
| `契约者.职业.名称` | 金/紫品质需对应生活系职业 |
| `契约者.当前世界` | 设施判定（回廊=主城设施；副本/现实=野外简陋） |
| `契约者.个人产业.当前店铺.设施清单` | 工作台等级判定（中级 -1 / 顶级全套 -3） |
| `契约者.背包` | 材料匹配、图纸物品检查 |

**读写：**

| 路径 | 写操作 |
|---|---|
| `契约者.背包` | 扣材料（bagRemove）、成品入包（bagAdd）、灰色废料入包、图纸物品入包 |
| `契约者.经济.UP` | 图纸购买扣款、设施使用费（spendUP） |
| `契约者.衍生属性.HP_当前` | 炸炉伤害：`-= 目标阶位×10`，clamp ≥ 0（无视防御） |
| `契约者.个人产业.*` | （v3）店铺注册/升级、代工订单、冻结资金 |

**小手机聊天变量（zod+pinia，watchEffect 持久化）：**

- `配方库`：玩家已登记的图纸配方 + 自定义配方（内置模板/标准配方不落库，代码自带）
- `材料档案`：`物品名 → {类别, 阶位, 品质}`，启发式自动归类 + 玩家手动修正
- `图纸备份`：`图纸名 → 配方 JSON`（购买时自动备份；背包物品 catchall 字段丢失时恢复）

## 5. 数据结构设计

### 5.1 配方（zod，图纸配方/自定义配方存聊天变量）

```ts
const 材料需求Schema = z.object({
  类别: z.enum(['金属','布料皮革','草药','矿石','能量','怪物素材','食材','火药','任意']),
  最低品质: z.enum(['任意','白色','蓝色','金色','紫色']).prefault('任意'),
  数量: z.coerce.number(),
  核心: z.boolean().prefault(false), // 核心材料：失败损毁计算 + 成品命名来源
});

const 配方Schema = z.object({
  名称: z.string(),                       // 配方名 = 成品基础名
  来源: z.enum(['模板','标准','图纸','自定义']),
  行业: z.enum(['锻造','裁缝','炼金','工程','烹饪']),
  成品类型: z.enum(['装备','消耗品']),
  装备子类: z.enum(['武器','防具','饰品']).or(z.literal('')).prefault(''),
  品质: z.enum(['白色','蓝色','金色','紫色']),
  阶位: z.coerce.number().transform(v => _.clamp(Math.round(v), 1, 5)),
  材料: z.array(材料需求Schema),
  需要职业: z.string().prefault(''),       // 金/紫：对应生活系职业名；空 = 无要求
  技能要求: z.object({
    分类: z.enum(['基础','高级']),
    等级: z.coerce.number(),
  }),
  需要图纸: z.boolean().prefault(false),   // 金/紫 = true
  效果: z.record(z.string(), z.string()).prefault({}), // 成品特效（图纸配方才有）
  批量上限: z.coerce.number().prefault(1), // 消耗品可 >1
});
```

### 5.2 图纸（背包物品形态）

```
名称: '图纸·狼王牙刃'
描述: 人类可读摘要（产物、材料清单、制作要求、特效）
数量: 1
图纸数据: { ...配方Schema JSON }   // 背包 catchall(z.any()) 允许，schema 合法
```

- 购买蓝图 → 图纸物品入包 + 配方登记进配方库 + 本地备份，三步一次结算完成。
- 制作金/紫时须对应图纸物品**在背包**，否则走"缺图纸"降档路径（DC+5、强制降一档品质）。
- 图纸可在市场转卖（v3）；买家在自己的配方库里看到它（图纸数据随物品走）。

## 6. 制作流程详设

### 6.1 前置校验（全部不满足则禁止开工并标明缺什么）

1. 成品阶位 ≤ min(契约者阶位, 生活技能阶位)
2. 技能要求：白=基础技能 Lv.1；蓝=基础技能 Lv.3；金=高级技能 Lv.1 + 对应生活系职业；紫=高级技能 Lv.5 + 职业 + 高阶材料（材料需求里最低品质=金/紫）
3. 金/紫：对应图纸物品在背包（否则允许强行开工但走缺图纸降档）
4. 设施：见 §8
5. 背包材料满足材料需求（按类别+品质从材料档案匹配，玩家确认具体用哪几件）

### 6.2 DC 计算（世界书公式逐字移植）

```
基础DC: 白10 / 蓝15 / 金20 / 紫25
修正: 缺图纸+5 / 越阶高级材料代替-2 / 劣质材料替代+3 / 野外简陋+3 / 中级工作台-1 / 顶级店铺全套工坊-3
最终DC = floor[(基础DC + 修正) × (1 + (阶位-1)/1.4)]
```

UI 逐项列出修正明细（透明可审计）。

### 6.3 检定与五档结果

```
检定值 = d20 + 行业对应基础属性 + 生活技能等级
行业属性: 锻造→STR / 裁缝→AGI / 炼金→PER / 工程→PER / 烹饪→CON或PER取高
```

| 结果 | 条件 | 效果 |
|---|---|---|
| 大失败 | d20=1 | 投入材料全毁；`HP_当前 -= 阶位×10`（clamp≥0） |
| 失败 | 检定值 < DC | 每种核心材料损毁 50%（向上取整），辅料保留；产出「灰色废料」x1 入包 |
| 成功 | DC ≤ 值 < DC+5 | 正常产出，数值在标准区间内随机波动 |
| 精制 | DC+5 ≤ 值 < DC+10 | 数值取满值；10% 概率附加 1 条微效词条（概率为可调常量） |
| 杰作 | d20=20 | 数值突破品质上限（不超过高一品质下限）+ 1 条特性词条 + 描述刻印「由${姓名}制造」 |

骰子由代码随机（gsap 动画展示），彻底替代世界书"GM 预埋骰池"的防口胡需求。

### 6.4 批量制作（消耗品）

一次检定、扣 N 份材料（N ≤ 配方批量上限）、出 N 件；失败时损毁材料按 N 比例放大。装备批量上限恒为 1。

## 7. 配方三层结构

### 第 1 层：参数化模板配方（内置，装备用）

装备数值在世界书中本来就是算法化的（类型+阶位+品质 → 查表），所以配方不带数值，只带"行业+子类+品质+阶位+材料类别要求"。

- 材料按**类别**匹配，不指定具体名：核心材料名自动成为成品名（精铁→精铁长剑；深渊魔狼王的牙→狼牙刃）
- 内置约 30 个模板：5 行业 × 装备子类 × 常用品质档
- 成品数值由 equipTables.ts 查表现算（见 §9）

### 第 2 层：标准道具配方（内置，消耗品用）

消耗品在世界书物价表中是标准化商品，直接内置固定配方约 20 种：

- 恢复类：基础治疗药剂(15) / 强效治疗药剂(40) / 急救包(80)
- 精神类：基础精神药剂(20) / 强效精神药剂(45) / 冥想熏香(70)
- 状态类：净化药剂(25) / 万能解毒剂(60) / 兴奋剂(35)
- 弹药类：普通弹药20发(10) / 穿甲弹药20发(25) / 元素弹药20发(30)
- 烹饪餐食、工程爆炸物/陷阱（数值按 §9 消耗品公式）

自制消耗品成品自动带：`自制: true` 标记、毒性值字段、描述注明"同类连用效果减半、毒性需医疗中心净化"。

### 第 3 层：图纸配方（AI 生成，金/紫及一切奇思妙想）

流程：

1. 玩家输入目标：想做什么（名称/类型/品质/阶位）、指定核心材料
2. `blueprint.ts` 组装提示词：世界书数值表与装备效果强度限制作为**硬约束**注入，要求返回配方 JSON
3. zod 校验 + 钳制（特效强度 ≤ 装备效果强度限制表；材料阶位 ≤ 玩家阶位；品质 ≤ 当前可做档）——与市场 `priceTable.ts` 强校验同套路
4. 标价（§7.1），玩家确认支付 UP → 图纸物品入包 + 配方入库 + 本地备份
5. 不付款则放弃候选，零变量变动

#### 7.1 图纸定价

> 装备图纸价 = 同类型同品质成品一阶价格区间中值 × 2 × 阶位系数(x²)
> 道具图纸价 = 成品单价 × 20 × 阶位系数(x²)

| 图纸 | 一阶 | 二阶 ×4 | 三阶 ×9 | 四阶 ×16 | 五阶 ×25 |
|---|---|---|---|---|---|
| 金·武器 | 1,200 | 4,800 | 10,800 | 19,200 | 30,000 |
| 金·防具 | 850 | 3,400 | 7,650 | 13,600 | 21,250 |
| 金·饰品 | 1,000 | 4,000 | 9,000 | 16,000 | 25,000 |
| 紫·武器 | 4,500 | 18,000 | 40,500 | 72,000 | 112,500 |
| 紫·防具 | 3,000 | 12,000 | 27,000 | 48,000 | 75,000 |
| 紫·饰品 | 3,700 | 14,800 | 33,300 | 59,200 | 92,500 |
| 金·强效治疗药剂 | 800 | 3,200 | 7,200 | 12,800 | 20,000 |
| 金·万能解毒剂 | 1,200 | 4,800 | 10,800 | 19,200 | 30,000 |
| 金·元素弹药配方 | 600 | 2,400 | 5,400 | 9,600 | 15,000 |

定价逻辑：图纸是生产资料（无限制作权），装备图纸回本 = 做 2~3 件成品卖出；道具图纸回本 = 20 份。×2 与 ×20 为可调常量。

## 8. 设施系统

| 场景 | 判定来源 | 效果 |
|---|---|---|
| 回廊主城设施 | `当前世界='回廊'` | 无修正，全品质可做 |
| 个人店铺中级工作台 | `个人产业.当前店铺.设施清单` 含中级工作台 | 基础DC -1 |
| 个人店铺顶级全套工坊 | 设施清单含顶级全套工坊 | 基础DC -3 |
| 野外简陋 | `当前世界='副本'/'现实'` 且无设施 | 基础DC +3，仅可做白色品质/基础耗材 |

## 9. 成品数值生成（equipTables.ts，世界书表格移植）

**装备：**
- 武器：白色全阶位速查表（徒手/匕首/短剑/长剑战斧/巨剑/突击步枪/重型狙击/魔杖/法杖 × 五阶 → 骰/倍率/负重）；品质升骰（白+0/蓝+1/金+2/紫银+3，路径 d4→d6→d8→d10→d12→d20→d40）
- 防具：光谱（极轻/轻/中/重/极重）一阶基准 × 阶位防闪倍率（1/2/4/7/11）
- 属性加成：主属性加成基准表（武器/躯干/饰品 × 阶 × 品质），副属性 = floor(主×0.5)
- 穿戴门槛：按阶位+类型基准 + 跨阶递增（二阶+20/三阶+40/四阶+60/五阶+80）
- 成品装备字段填满 `装备槽Schema` 全字段后入背包（背包 describe 要求装备类含完整字段）
- dice.ts 已有奖励骰表可复用则复用，缺失部分移植

**消耗品：**
- 恢复类：恢复量 = 固定数值 + 制作者 PER/CON 修正 × 阶位倍率
- 伤害类（爆炸物/陷阱）：伤害 = 品质骰（一阶白2d6/蓝4d6/金6d6）+ 制作者对应属性修正 × 道具阶位系数

**银色品质不可制作**（校验硬拦截）。

## 10. 成品描述

- **模板自动生成**（默认，零延迟零 token）：结构化字段渲染（名称/类型/品质/阶位/数值/效果），装备名 = 核心材料名+类型词
- **玩家手动编辑**：描述、名称可改
- **AI 吐槽**（可选按钮，任意成品可用）：调 `generate`，输入成品字段+制作者名+材料名，输出一段**惊悚乐园风毒舌备注**追加到描述。提示词风格锚点：系统播报式字段 + 毒舌点评（拿材料来源、制作者、数值开涮，例如："剑是好剑，就是不知道那头魔狼看见自己的牙被磨成这玩意儿会作何感想。哦对了，制作者署名是'老狼'，很难不让人怀疑这里面有什么私人恩怨。"）

## 11. UI 结构

桌面新图标「工坊」🛠️ → 三页签：

1. **配方**：模板/标准/图纸/自定义四个分区；每个配方显示解锁状态与缺失条件（技能不够/没职业/没图纸/没设施）；图纸配方卡上有「AI 定制图纸」入口
2. **制作**：选配方 → 材料选择（类别匹配出候选，玩家确认具体投入哪些，可切换劣质/越阶高级材料触发对应 DC 修正）→ 设施选择 → DC 明细 → 掷骰动画 → 五档结果演出 → 结算写回
3. **材料**：背包材料视图（按类别筛选）、材料档案管理（改归类）、缺口高亮

## 12. 分期

- **v1 制作台核心**（零 AI）：配方库 UI（模板+标准）、材料档案（启发式+手动）、DC+检定+五档、白/蓝制作、成品入包+模板描述+手动编辑、设施判定
- **v2 图纸系统**：AI 生成+zod 校验+UP 购买+背包图纸物品+金/紫制作+AI 吐槽备注
- **v3 店铺与市场**：店铺注册/升级（写 `个人产业`）、成品/图纸挂自由市场（**注意：`priceTable.ts` 与 `cloudflare/wxhl-market/worker.js` 价格规则需两边同步**，图纸为新品类）、材料收购悬赏、代工橱窗（写 `代工与订单`）

## 13. 测试策略

照 `market/__tests__` 模式（vitest）：

- `craft.test.ts`：DC 公式边界（各品质/阶位/修正组合）、五档判定（含 d20=1/20 优先于总值判断）、核心材料 50% 损毁取整、批量制作、HP 扣减 clamp
- `recipes.test.ts`：内置配方数据合法性（过配方Schema）、材料分类词典归类正确性
- `blueprint.test.ts`：定价公式（对照决策表全格）、zod 钳制（超强度特效被压回、银色被拦截）
- `equipTables.test.ts`：抽查世界书示例（金三阶短剑 = 6d10/0.75/2.7kg；蓝五阶重狙 = 14d10/0.5/24kg）

## 14. 风险与开放问题
