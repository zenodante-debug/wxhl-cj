## 🔴 最要紧的四条

### ① 时间更新到底生效没有（终审抓到的 Critical，必须实测）

终审发现原来 `store.ts` 把「现实时刻」当「现实日期」喂给了计算函数，导致**这一步从来没生效过**。已修，但**修复只钉在纯函数层，store 那一行没有自动化测试** —— 只能你实测。

- ⬜ 结算前记下 `当前时间.现实日期`（形如 `2025年5月10日`）
- ⬜ 确认你知道**本次副本过了几天**（看 `当前时间.客观时间`）
- ⬜ 结算后看 `当前时间.现实日期` **是否加了那么多天**
- ⬜ 面板上 `## 现实时间` 那行**不该**出现「现实日期格式无法识别」

**没加上 → 立刻告诉我**，那说明接缝还没修对。

### ② `客观时间` 的格式（AI 判天数的依据）

天数由 **AI 读 `当前时间.客观时间`** 得出，模块不解析它。而**那个字段的实际写法我不掌握**（仓库里看不到你的卡）。

- ⬜ 看一眼 `客观时间` 到底是什么格式（纯数字？`3天`？`第3天`？）
- ⬜ 面板 `## 现实时间` 的日期增量与它**对得上吗**
- ⬜ 对不上就把 `客观时间` 的实际内容发我，我调 prompt 措辞

### ③ 写进存档的每一个数对不对

结算**累加**语义（`旧值 + 增量`），且**不可撤销**。请逐项核对：

- ⬜ `头部.EXP_当前` / `经济.UP` / `头部.RP_当前` / `职业.PEXP_当前` —— 各加了正确的增量
- ⬜ `头部.CR` / `头部.回廊态度` —— 按评价等级变动（S+0.5 / A+0.3 / B、C 不变 / D-0.5；≥10 回调至 3）
- ⬜ **`资格分` = 旧值 + 本次**（面板印的是「本次」，UI 上另有「赛季累计（结算后）」= 新值）
- ⬜ `赛季信息.当前副本周期` +1（10 → 1）
- ⬜ `副本经历.<副本名>` = `{评价等级, 简要说明}`
- ⬜ **小队每个成员的 `头部.EXP_当前` 与 `背包.现金UP.数量`** —— 应与玩家拿到**完全相同**的增量
- ⬜ 掉落物品进了 `背包`，且**数量是累加**（你原有的同名物品**不该被冲掉**）
- ⬜ `其他契约者` / `副本角色` / `其他契约者名单` / `固有角色名单` **已清空**
- ⬜ `当前副本元数据` / `当前副本任务` **已清零回默认**

### ④ 存档里不该出现被禁字段

- ⬜ 写入后，**不该**出现 `属性.*` / `衍生属性.*` / `称号.当前称号` / `头部.军衔` / `头部.EXP_升级所需` / `头部.RP_下一级` / `职业.职业等级` / `职业.PEXP_升级所需`
  （前几项由前端脚本代算；后几项由前端脚本维护 —— 模块**只加增量**，不做晋升/升级）

> 有自动兜底：写入后有逐条回读校验，字段名对不上会弹
> `写入未生效: 字段名与存档 schema 不匹配 → 路径`。**看到就把报错发我。**

- ⬜ 被 `<Settlement Beautification>` 包裹，含 `<基础结算奖励>` 与 `<特殊结算奖励>` 两个子块
- ⬜ 28 条 `## ` 行齐全（最终评价/评价倍率/CR态度/CR奖励倍率/位阶修正/基础EXP汇总/基础UP汇总/最终EXP/最终UP/RP获得/当前RP余额/军衔状态/PEXP获得/当前PEXP/职业进度/称号获得/称号效果/称号选择/掉落清单/副本成就已达成/副本成就未达成/隐藏任务公示/CR变动/更新后CR/回廊态度/史诗记录/副本周期/现实时间）
- ⬜ `## 最终评价` 形如 `S+185`（**不该**出现字面的 `（）`）
- ⬜ `## 当前PEXP` 与 `## PEXP获得` **不是同一个数**（前者是余额、后者是本次）—— 与 `当前RP余额`/`RP获得` 同构
- ⬜ `## 副本成就未达成` **列出了你错过的成就及其达成条件**（不是一句占位说明）
- ⬜ 画面末尾有「结算后流程」的两个选项（休息周期 / 花 UP 延长滞留），并说明**在聊天里告知选择**

### ⑥ AI 判定质量（只能肉眼看）

- ⬜ 评价等级合理（S 的条件极苛刻：主线完美+全部支线+隐藏+无濒死+1~6星成就）
- ⬜ 击杀数/濒死次数与你的实际经历相符
- ⬜ 掉落物品有副本特色，且考虑了 CR 掉落加成
- ⬜ 称号仅 A/S 级才给；史诗记录是「中二诗意」的一句话
- ⬜ **面板上的数字与模块算的一致**（面板由模块拼装，理论上必然一致 —— 这是设计保证）

### ⑦ 不可逆操作前的保护

- ⬜ 「确认结算」前有**不可撤销**的提示
- ⬜ 写入中「重算」「确认」「放弃」都被禁用
- ⬜ **写入后若回读失败**，应看到「变量已写入存档，请先读存档确认，**不要直接重试**」，且三个按钮被锁
  （⚠️ **这是防「重复结算把数值翻倍」的机制** —— 若你看到它，**照它说的做**，别手快再点）
- ⬜ 「放弃本次结算」有二次确认，且说明「不会撤销已写入的结算」

### ⑧ 面板与存档同源

- ⬜ 把面板上的 `最终EXP`/`最终UP`/`当前RP余额`/`当前PEXP`/`更新后CR`/`副本周期` 与存档里的对应值**逐项对一遍**，应当**完全一致**

### ⑨ 「填入输入框」—— 送玩家进结算空间（**这一节最要紧，有两条只能实测**）

确认结算后，操作组里应有「**填入输入框**」（**只填入、不发送**）。

- ⬜ 未写入存档时它**不可点**；写入成功后**可点**
- ⬜ 点它 → 输入框里出现一段提示词，**且没有自动发送**

**🔴 然后是最关键的一步 —— 看 AI 收到之后干了什么：**

- ⬜ **AI 有没有重新跑一遍结算？**（那会让 EXP/UP/RP/PEXP/资格分**翻倍且不可撤销**）
  填入后**先记下存档里的四个增量**，让 AI 回一段，**再看一遍存档** —— 数值**必须没变**。
  **若变了 → 立刻告诉我**，这是这个功能最严重的失效模式。
- ⬜ **AI 有没有冒出结算面板**（`<Settlement Beautification>` 或「## 名称: 值」式的行）？
  ⚠️ 这条是**已知的、只能实测的风险**：提示词里为了让 AI 别输出面板，**点名了那个格式** —— 有可能反而在给它提示。
  **若它真冒出来了 → 告诉我，我把那句删掉**（删掉后提示词就完全不含规则里的任何格式名，代价极小）。
- ⬜ AI 的叙事应当是**回廊结算空间的场景**，末尾**列出两个选项**（休息周期 / 花 UP 延长滞留）

### ⑩ 已知的、不影响使用的观察项

- ⬜ 卡片上的「基准等级 Lv.X」可能显示的是**裸玩家等级**（没算 CR 偏移）—— **仅显示层**，写进存档与生成敌人用的都是正确的值
- ⬜ 若 `toastr` 因故抛错，画面可能显示「回读校验失败」而那次写入其实成功了 —— 内部自洽、方向保守（不会翻倍），**刷新页面即可**

## 已知取舍（不是 bug，交付时说明）

1. **面板严格照规则模板输出、不加行** —— 所以「资格分逐项（评价分/击杀分/任务分）」与「赛季累计」放在**手机 UI 上**而不是面板里。
2. **`## 掉落清单` 是「本次掉落量」，存档里 `背包.数量` 是「余额」** —— 语义不同，不是不一致（UI 上有说明）。
3. **`## 军衔状态` / `## 职业进度` 是照抄现有字段** —— 模块不做晋升/升级（那是前端脚本的活）。前端若没维护，会显示 0 或旧值。
4. **结算后流程不在模块里** —— 画面列出两个选项，由聊天里的 AI 接手。
5. **`头部.阶位` 的写法必须在 `一阶`~`五阶` / `1阶`~`5阶` / `1`~`5` 之内** —— 落在外面**整次结算会被挡住**（宁可挡住，也不静默少给 5 倍 EXP）。若被挡住，报错信息里会显示那个可疑的阶位原值。
6. **奖励文本格式非法会明确报错**，不静默当 0。
