# 战斗脚本 · 决斗场美术（UI 美术专项）— 实施计划

日期：2026-10-08
范围：`src/wxhl-combat/`（纯视觉层，不动引擎逻辑）
裁决（玩家已拍板）：
1. **美术方向**：继承 wxhl-003「里世界长廊」视觉语言（调色板/字体/颗粒纹理/铆钉），战斗页构图为**决斗场**
2. **范围**：全套统一 —— 悬浮窗外壳（顶栏/页签/启动球）+ 准备页 + 战斗页 + 收尾页 + 设置页
3. **动效**：**重演出**（攻击轨迹 / 伤害飘字 / 变身演出 / 濒死表现 / 环境火光），全部可一键关闭

## 1. 视觉语言（从 wxhl-003 继承的 token）

### 1.1 调色板（CSS 自定义属性，挂在 `.wxhl-combat-root` 上）

CSS 变量而不是 SCSS 变量 —— 因为所有视图都渲染在 App.vue 的根里，
`var(--cb-*)` 天然穿透 scoped 样式，不需要每个组件 `@use` 一份。

```
--cb-void    #080504   底色（决斗场外的虚空）
--cb-bg      #120b07   场地面
--cb-panel   #241812   石碑面板
--cb-panel-2 #2e1e14   石碑亮面
--cb-border  #4a3226   铜边
--cb-amber   #e8c078   琥珀（标题/强调）
--cb-chalk   #e8dfd2   粉笔白（正文亮）
--cb-dim     #7d6c58   弱文字
--cb-blood-wet #d05040 鲜血（伤害/敌方）
--cb-blood   #4a1010   沉血（血条底）
--cb-ember   #d8914a   火光
--cb-gold    #d0a850   金（胜利/钥匙）
--cb-copper  #6a9070   铜绿（我方/治疗）
--cb-mana    #5a7da8   蓝（MP/护盾）—— wxhl-003 没有的战斗专色
```

### 1.2 字体与纹理

- `Noto Serif SC`（标题/铭牌，400/700/900）、`Noto Sans SC`（正文）、`JetBrains Mono`（数字/骰值）—— 与 wxhl-003 同源，`@import` 一次（App.vue 顶层样式块）。
- **SVG feTurbulence 颗粒纹理**（自包含 data URI，无图片资源）—— 直接搬 wxhl-003 的 `--sb-grain`。
- **铆钉 mixin**（铭牌四角）—— 搬 wxhl-003 的 `sb-rivets`。
- 火光/灯泡摇曳关键帧 —— 搬 `sbBulbFlick`，决斗场改为火把。

### 1.3 不动的东西

`mobile-compat.js`（外壳定位/拖拽）、`index.ts` 的根样式与 z-index、launcher 的可点区域与事件 —— 只换皮，不改行为。

## 2. 页面构图

### 2.1 悬浮窗外壳（App.vue）

- **顶栏** → 石檐：暗棕渐变 + 颗粒 + 底部铜线，标题「无限回廊 · 决斗场」用衬线琥珀字，页签做成**铜牌**（选中态：琥珀描边 + 微光）。
- **启动球** → 铜环嵌宝石：圆形铜边 + 中心血珀（发光脉动），保留现有尺寸/拖拽/位置逻辑（`mobile-compat.js` 管行为，这里只换 `combat-launcher` 的皮肤）。

### 2.2 准备页（SetupView）

- 中央**契约者铭牌**构图（搬 wxhl-003 的 center-plate：铭牌 + 台座 + 向上打光）：名单选择做成铭牌列表，敌我分配做成左右两列石门。
- 「开战」按钮做成**决斗场闸门**：大石牌 + 铆钉 + 血色 hover。

### 2.3 战斗页（BattleView + CombatView 横幅）—— 重点

**自上而下三段：**

1. **决斗场横幅**（CombatView）：石檐横匾 —— 回合数（衬线大字）、先攻链（一列火把图标，当前行动者火把点亮，倒下的熄灭）、敌方意图区（羊皮纸条）。
2. **决斗场地面**（距离轴重画）：
   - 一维距离轴画成**地砖透视延伸线**：中央是玩家原点（铜环标记），向前向后延伸，地砖格线用 CSS 渐变画；距离带分界处画浅色刻痕。
   - 角色标记 = **棋子铭牌**（小石牌 + 名 + 血条），同一坐标上下排列（逻辑已有，只换皮）；敌方棋子铜色带血边，我方棋子铜绿边；濒死棋子倒扣（变灰 + 斜置）。
3. **双方军牌 + 行动石碑**（BattleView）：
   - 单位卡 → **石质铭牌**：铆钉四角、衬线名、HP 血条做成**血色液面**（渐变 + 液面微光）、MP 蓝条、耐力铜条、护盾画成一层蓝色釉光。
   - 状态/增益 → **蜡封图标**列（小圆印 + tooltip）；冷却中画成灰色刻痕。
   - 行动区 → **石碑**：下拉做成铜牌选项，「执行本轮」是大闸门按钮；行动顺序条目做成可拖的小石牌（↑↓ 保留）。
   - 详情面板（效果详情/装备/状态）→ 展开的**卷轴**。
   - 战斗日志 → **羊皮纸卷轴区**（等宽字，命中/伤害用血色，规则系用金色）。

### 2.4 收尾页

- 胜利：**金漆横幅**「凯旋」+ 钥匙掉落列表（白/白银/黄金/钻石/血腥五档各配一色图标）。
- 败北：血字横幅「陨落」+ 暗场。
- 逃离：灰字「撤退」。

### 2.5 设置页

- 与外壳统一：石碑面板 + 铜牌开关 + 琥珀链接色。新增**「战斗演出」开关**（见 §3）。

## 3. 重演出动效（可一键关闭）

**数据来源**：演出不猜 —— 全部从 `结算步骤[]`（已经有的日志结构）解析出"事件"（纯函数，可单测）：
`engine/showEvents.ts`：`演出事件提取(步骤) → [{类:'命中', 攻方, 守方, 伤害?}, {类:'变身', 单位, 形态}, {类:'打断', 单位}, {类:'濒死', 单位}, {类:'规则系', 效果}]`

| 演出 | 做法 | 触发事件 |
| :--- | :--- | :--- |
| **伤害飘字** | 在守方棋子位置冒出一个血数字，上升淡出（CSS transform/opacity）；暴击更大更金 | 命中（伤害>0） |
| **攻击轨迹** | 攻方棋子 → 守方棋子的一道短暂光束（SVG line + dash 动画，0.4s） | 命中/未命中（未命中是灰色轨迹） |
| **变身演出** | 全屏压暗（0.3s）→ 中央大铭牌亮出「二阶段·觉醒」+ 血光脉冲 → 收回 | 切换形态 / 「已X阶段」词条落地 |
| **濒死** | 棋子倒扣 + 牌面血色滴落（CSS 渐变动画）+ 横幅提示 | HP 归零（标记濒死） |
| **打断** | 守方棋子炸开一圈金色裂纹闪光 | 打断成功 |
| **规则系** | 相关棋子套一层对应色光环（穿透=白、即死=黑红、无敌=金）一瞬 | 规则系判定通过 |
| **环境** | 决斗场两侧火把摇曳（搬 sbBulbFlick 改色），场地边缘血色环境光呼吸 | 常驻 |

**性能与开关**：
- 全部 transform/opacity 动画；飘字层 DOM 上限 24 个（超出即弃，不排队）。
- 设置项 `演出: true|false`（store 设置，zod 默认 true）；`@media (prefers-reduced-motion: reduce)` 一律等同关闭。
- 关闭时演出层整体不渲染（`v-if="演出开 && 尊重减弱动效"`），零成本。

## 4. 样式架构

```
src/wxhl-combat/
  theme.scss            ← token（CSS 变量挂在 .wxhl-combat-root）+ 颗粒纹理 + 铆钉/石牌/铜牌 mixin + 关键帧
  App.vue               ← 外壳换皮（石檐顶栏/铜牌页签/宝石启动球）+ @import 字体
  views/SetupView.vue   ← 契约者铭牌 + 石门名单 + 闸门开战键
  views/BattleView.vue  ← 决斗场地面 + 军牌铭牌 + 石碑行动区 + 卷轴日志
  views/CombatView.vue  ← 决斗场横幅（回合/先攻火把链/意图羊皮纸）+ 演出层挂载点
  views/SettleView…     ← 收尾横幅（在 CombatView 内）
  views/SettingsView.vue← 石碑设置页 + 「战斗演出」开关
  engine/showEvents.ts  ← 结算步骤 → 演出事件（纯函数）
  views/ShowLayer.vue   ← 演出层（飘字/轨迹/变身/濒死/打断/规则系光环）
```

- `theme.scss` 只放变量/mixin/关键帧（零选择器输出），各组件 `@use` 后写自己的 scoped 样式 —— 符合脚本.mdc 的隔离要求。
- 演出层是一个独立组件 `ShowLayer.vue`，覆盖在决斗场区域上（`position:absolute; pointer-events:none`），接收演出事件数组。

## 5. 实施步骤（每步可独立验证）

1. **theme.scss + 外壳换皮**：token/纹理/铆钉/关键帧；App.vue 石檐+铜牌+宝石球。验证：renderViews SSR 断言根上有 CSS 变量、launcher class 存在。
2. **准备页**：铭牌 + 石门 + 闸门。验证：renderViews 断言构图 class。
3. **战斗页静态皮**：决斗场地面（地砖轴）、军牌铭牌、石碑行动区、卷轴日志、横幅。验证：renderViews 断言 + 距离轴几何既有测试不破。
4. **showEvents 纯函数 + 单测**：从结算步骤提取演出事件（命中/变身/打断/濒死/规则系）。
5. **ShowLayer 演出层**：飘字/轨迹/变身/濒死/打断/规则系光环 + 环境火光。验证：renderViews 注入事件数组断言渲染；DOM 上限测试。
6. **演出开关**：store 设置项（zod 默认 true）+ SettingsView 开关 + `prefers-reduced-motion` 短路 + 源码守卫。
7. **收尾页**：凯旋/陨落/撤退三态横幅。
8. **设置页统一**：石碑化。
9. **全量回归**：`npx vitest run`、`npx tsc --noEmit`（基线 44）、`npm run build`、`bash scripts/push-combat.sh`。

**不做**：引擎逻辑、mobile-compat 行为、launcher 位置/拖拽逻辑、页面信息结构（只换皮不换信息层级）。

- 老守卫全绿：renderViews/viewScriptScope/源码守卫 + 全部 1738 个既有测试。

## 7. 风险

| 风险 | 对策 |
| :--- | :--- |
| scoped scss 里 CSS 变量作用域 | 变量只挂 `.wxhl-combat-root`（App.vue 非 scoped 顶层块定义），组件一律 `var(--cb-*)` |
| 演出层遮挡操作 | `pointer-events:none` + z-index 低于行动区 |
| 手机端演出掉帧 | 只 transform/opacity；飘字 DOM 上限；火把动效 `animation-play-state` 随开关停 |
| Google Fonts @import 在酒馆页面 | wxhl-003 已验证同法可行；失败时回退系统字（serif/sans 栈已写） |
| 演出事件解析把日志格式当 API | 解析只认 `步骤.类` + 结构化字段，**不解析内容文本**（文本会变，类名是契约） |
