## 🔴 最要紧的三条

### ① 面板数字必须来自前端代算，不能是模块自算

写入成功后，看弹出的提示是哪一条：

| 你看到 | 含义 | 该做什么 |
|---|---|---|
| `…（面板数值取自前端代算结果）` | ✅ 走的是**回读你卡里前端脚本**算出的值 | 扫一眼数字像不像真的 —— **尤其别是 `100/100` 这种整数** |
| `…前端脚本尚未代算, 面板为模块自算值` | ⚠️ 你卡的 `衍生属性` **没人填** | **立刻告诉我**，并把卡里 `衍生属性` 那几行 schema 发我 |

- ⬜ **这一条是整轮修复的核心。** 之前模块按「实际 = 基础」自算，7 件金装的 BOSS **HP 会低估约一半**（112 vs 900 那种差距）。

### ② `confirm()` 到底弹不弹得出来（必测）

`I2` 的裁决是：写入**已存在**的同名角色前弹一次确认框，取消就跳过。

**风险**：如果酒馆的 iframe sandbox 拦住了原生模态，`confirm()` 会**立即返回 false** → 所有已存在角色被静默跳过。

- ⬜ 先写一次三个角色 → 再点一次「敌人生成」→「写入选中的」
- ⬜ **确认弹窗真的出现了**（列出已存在的角色名）
- ⬜ 点「取消」→ 应提示 `已取消, 未写入任何副本角色`
- ⬜ 点「确定」→ 应正常覆盖

**若弹窗没出现却直接提示「已取消」→ 告诉我**，我改用「已存在的项默认不勾选」的方案（不依赖模态）。

### ③ 存档里不该出现被禁字段

- ⬜ 写入后读存档，`契约者.副本角色.<角色名>` 里**不该有**：
  `属性.加成` / `属性.实际` / `属性.属性修正值` / `HP_最大` / `MP_最大` / `耐力_最大` / `防御` / `闪避值` / `移动距离` / `负重_上限` / 任何 `*_当前`
- ⬜ 应该**有**：`外貌` `类型` `构筑` `好感度` `头部`（等级/阶位/天赋/血统/称号）`属性.基础` `属性.自定义加成` `衍生属性` 的 **7 个「额外加成」** `通用技能` `装备` `状态.特殊状态` `背包`（+ BOSS 的 `职业`）
- ⬜ **你卡里的前端脚本能正常代算**（状态栏/衍生属性有值，没有报错）

> 这一条**本身就有自动兜底**：写入后有回读校验，若某个键在你卡里不存在，会弹
> `写入未生效: 字段名与存档 schema 不匹配 → 副本角色.<名字>`。
> 看到它 = 我的键名猜错了，**把那行报错发我**。

## 🟡 其余

### ④ 三个角色的数值合不合理

- ⬜ 等级 = 基准等级 × 系数（杂兵 0.6 / 精英 0.9 / BOSS 1.2）四舍五入 —— 基准等级就是你的等级
- ⬜ 阶位由等级落入区间（一阶 1~20 / 二阶 21~40 / …）
- ⬜ **三者都要有本次副本的特色**，不是通用模板（技能/装备/天赋/职业/血统与副本世界观察相关）
- ⬜ BOSS 有 `[职业]` 行，杂兵与精英**没有**
- ⬜ 装备的 `装备防御`/`装备闪避` 是**算好的绝对值**（不是 0，也不是占位）
- ⬜ `[底牌]` 行有称号/天赋/血统；BOSS 的天赋血统有独有机制

### ⑤ 面板格式

- ⬜ 面板被 `<enemy>…</enemy>` 包住
- ⬜ 有这些行：`[名称|` `[类型|` `[外观|` `[生命|` `[威胁|` `[属性|` `[防御|` `[底牌|` `[装备|` `[技能|`
- ⬜ `[装备|` 行按**七槽顺序**（头部/躯干/手部/下装/饰品/主武器/副武器），没有的槽写「无」
- ⬜ `[威胁|` 是 AI 给的评估（如「极低单体，集群麻烦」），**不是** `一阶 · Lv.11` 那种回退文本
- ⬜ **出现 `—` 是正常的**（表示那个数算不出来），但**不该满地都是 `—`** —— 满地都是就告诉我
- ⬜ **若 `[属性|` 行里的阶位不是「一阶」~「五阶」这五种写法之一**（例如 AI 漏写成了「无」），
  那么 `[生命|` 与 `[防御|` 会印 `—` —— 这是**故意的**：宁可不给数，也不按错误的位阶系数给一个偏得离谱的数（五阶按一阶算会差 11 倍）。
  **看到这种就把那个阶位原值告诉我。**
- ⬜ `[生命|` 印了 `—` 时，`[负重|` 之类的值**不受影响**（负重不依赖阶位，照常算）

### ⑥ 世界书依赖

- ⬜ 卡片上有提示：三种副本角色的**生成规则已内置**，但规则引用的系统模块（`<技能模版和限制>` / `<装备效果强度限制>` / `<装备与消耗品系统>` / `<天赋系统>` / `<血统系统>` / `<特殊技能模版>` 等）**需要你在「终端设置 → 世界书」里勾选**
- ⬜ 确认这些条目已勾上；否则生成的数值没有依据

### ⑦ 写入期间的操作互斥

- ⬜ 点「写入选中的」后，写入过程中 **🔄 重roll / 敌人生成 / 历史记录行 / 删除** 应该都点不动（最长约 2 秒）
- ⬜ 写完之后它们恢复可点
- ⬜ **若按钮永久变灰** → 刷新页面并告诉我（已知的极端情况：MVU 初始化卡住）

### ⑧ 勾选行为

- ⬜ 默认三个全勾
- ⬜ 取消一个 → 只写两个
- ⬜ 切换历史条目 → 勾选状态**重置为全勾**（不带上一条的状态）

## 已知取舍（不是 bug，交付时说明）

1. **生成后、写入前不给面板预览。** 因为面板数值要等写入后回读前端代算结果才能拿到 —— 宁可不给，也不给一个注定偏低的数。生成后只显示三个角色的 名称/类型/等级，供你决定勾选哪几个。
2. **本模块只生成 杂兵 / 精英 / BOSS 三种**，不生成隐藏BOSS与固有角色（规则原文说它们不参与主线难度计算、由隐藏任务或主动探索触发）。
3. **不新增 store/UI 测试**：测试环境够不到 `Mvu` / `toastr` / 酒馆全局。风险最高的纯逻辑（校验、映射、面板拼装）已被 123 条单测覆盖。
